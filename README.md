# 学习目标管理台 · Check-in Activity

一个「以打卡驱动学习目标推进」的个人工作台：设定目标 → 每日打卡 → 自动推算进度与预计完成日 → 每周复盘。

页面**零外链、零图片、零框架**，单个 HTML 文件即可运行；数据**不存浏览器本地**，而是存在云端数据表里，多端打开同一份数据，支持双向同步。

## 功能

**四个 Tab**

- **今日** — 今天该做什么、打了多少；未打的目标一键补记（可改日期，不局限于今天）
- **看板** — 每个目标的进度环、已完成 / 总量、预计完成日、状态
- **周报** — 近 14 天打卡折线（SVG 手绘，无图表库）+ 四格复盘：保持 · 问题 · 尝试 · 下周预案
- **我的** — 单位偏好、休息日规则、JSON 全量导出 / 导入

**核心算法**

- **近 7 天回溯均速**：取最近 7 天（含今天），按休息日规则剔除无效天后算日均
- **ETA**：`ceil((总量 - 已完成) / 日均)`，总量未填时**不编数字**，只提示补齐
- **四态判定**：`已完成` / `已逾期` / `可能延期`（ETA 超出截止日） / `正常推进`

**数据同步**

- 所有写操作**先落草稿、再写远端**，失败不静默——错误会显式呈现，草稿保留可重试
- 页面加载时从数据表拉取，读写均经 `__SMART_PAGE__.database`，因此**换设备、换浏览器数据一致**

## 设计系统

**学术纸感（Academic Paper）** —— 低饱和、弱对比，长时间看不累。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--paper` | `#f6f2e9` | 页底（纸色） |
| `--brand` | `#1d5346` | 主色（深松绿） |
| `--font-serif` | `Georgia, serif` | 标题与数字 |
| 栅格 | 8px | 间距与圆角基数 |

配色板为 8 色低饱和循环：`#2c6b5c #9a6b2e #a2382c #3a6b8c #6b5a8c #8c5a3a #4a8c5c #7a7a3a`

响应式覆盖 **320px → 1920px** 九档宽度，手机横屏单独适配；无横向溢出，长标题不断字。

## 数据模型

三张表（云端）：

| 表 | 作用 | 关键字段 |
|---|---|---|
| 学习目标 | 目标定义 | 名称、单位、总量、已完成、截止日、配色、排序 |
| 每日打卡记录 | 每天每条目标的增量 | 目标、日期、数量、备注 |
| 每周复盘 | 每周一份四格复盘 | 周起始日、保持、问题、尝试、下周预案 |

复盘按**周起始日复用**：同一周重复保存是更新而非新增。

## 构建与验证

**要点：交付的单文件版是由 `build/` 里的片段拼出来的，且可逐字节复现。**

```bash
cd build
python merge.py            # p1 + p2 + <script>final_script.js → ../学习目标管理台.html
```

合并结果与提交的 `学习目标管理台.html` **必须逐字节一致**；这是判断「产物有没有被手工改过」的唯一标准。

验证三件套：

```bash
node build/smoke.mjs       # DOM 渲染、空态、离线降级、设计令牌断言
node build/shots.mjs       # 320/360/390/430/834/1024/1280/1440/1920 实拍 + 溢出扫描
node build/check.js        # jsdom 结构检查
```

> `build/` 里还留有若干一次性排障脚本（`dbg*`、`fix_*`、`unmangle*` 等），是构建过程的历史痕迹，不参与构建。

## 本地运行

**工程化版**

```bash
cd app
npm install
npm run dev          # http://localhost:5173
npm run build        # 产物在 app/dist/
npm run typecheck    # 仅类型检查
```

**单文件版**：直接用浏览器打开 `学习目标管理台.html` 即可。
页面依赖云端 SDK 提供数据；离线打开会走降级路径，UI 正常渲染并在空态提示，不会白屏。

## 部署

单文件版：把 `学习目标管理台.html` 放到任意静态托管即可（GitHub Pages / Vercel / Netlify / 对象存储）。

工程化版：

```bash
cd app && npm run build
# 将 app/dist/ 上传
```

Vercel 连接仓库时：Framework 选 **Vite**，Build Command `npm run build`，Output Directory `dist`（Root Directory 设为 `app`）。

## 工程约定

- **敏感信息绝不入库**：`VITE_*` 密钥、令牌、签名 URL 一律走环境变量；`.gitignore` 已覆盖 `.env*`、`*.key`、`*.pem` 等
- **不静默失败**：写远端出错必须显式提示，不允许假装成功
- **不编造数字**：数据不足时显示提示语，而不是 `0`
- **单一出口转义**：所有动态文本经统一的转义函数进入 DOM
- **产物可复现**：改动源片段后重跑 `merge.py`，产物必须与仓库中的文件一致
